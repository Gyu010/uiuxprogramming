## 4주차 반응형 수정 

### 확인한 문제
작은 화면에서 메뉴, 기능 카드, 문제 입력 폼이 좁게 보였다.

### 수정한 내용
- viewport 메타 태그를 추가했다.
- 콘텐츠에 width와 max-width를 함께 사용함
- 기능 카드 목록을 반응형 grid로 변경
- 768px 이하에서 메뉴, 카드, 폼을 한 열로 구성함
- 전체 콘텐츠의 좌우 여백을 24px에서 20px로 조정함
- 이미지의 최대 너비를 720px에서 700px로 조정함
- 기능 카드의 최소 너비를 260px에서 250px로 조정함
- 기능 카드 사이의 간격을 24px에서 20px로 조정함
- 768px 이하 화면에서 좌우 여백을 16px로 조정함
- 모바일 화면의 h1 글자 크기를 36px에서 34px로 조정함

### 확인할 화면 너비 

1100px / 769px / 768px / 390px

## 6주차 JavaScript 이벤트 및 동적 UI

### 구현한 이벤트
- click 이벤트: 화면 테마 버튼과 기능 탭을 클릭하면 화면이 변경됨
- input 이벤트: 사용자 이름을 입력하면 현재 글자 수가 표시됨
- change 이벤트: 문제 정보 확인 체크박스를 선택하면 안내 문구와 버튼 상태가 변경됨

### 화면 변화
- 다크 테마 버튼을 누르면 화면 색상과 버튼 문구가 변경됨
- 사용자 이름 입력 시 글자 수가 표시됨
- 체크박스를 선택하면 안내 문구의 내용과 스타일이 변경됨
- 체크박스 상태에 따라 문제 해결 시작 버튼이 활성화 또는 비활성화됨
- 탭을 클릭하면 선택된 탭의 스타일이 변경되고 해당 내용만 표시됨

### 탭 UI
- 문제 유형 확인
- 단계별 해결 방법
- 문제 해결 기록

### 테스트 결과
- 1100px: 정상 작동
- 768px: 정상 작동
- 390px: 정상 작동
- click, input, change 이벤트 정상 작동
- 탭 3개 정상 작동
- 화면 잘림 및 가로 스크롤 없음


## 7주차 사용자 흐름 구현

### 주요 사용자 및 목표
- 사용자: 컴퓨터 문제 해결이 어려운 초보 사용자
- 목표: 컴퓨터 문제에 맞는 기본 해결 방법 확인
- 완료 조건: 문제 해결 안내를 확인하고 완료 버튼 클릭

### 사용자 흐름
1. 시작: 체크박스를 선택하고 문제 해결 시작
2. 입력: 문제 유형 선택 및 증상 입력
3. 확인: 입력 내용과 해결 방법 확인
4. 완료: 완료 메시지 확인 및 다시 시작

### 구현 기능
- 필수 입력값 검사 및 오류 메시지 표시
- 이전 단계 이동 시 입력값 유지
- 입력값 수정 후 확인 화면에 반영
- 문제 유형별 기본 해결 방법 표시
- 완료 메시지 출력
- 다시 시작 시 입력값과 진행 상태 초기화

### 테스트 결과
- 시작부터 완료까지 정상 작동
- 필수값 누락 검사 정상 작동
- 이전 단계 이동 및 입력값 유지 정상 작동
- 수정한 내용 정상 반영
- 다시 시작 기능 정상 작동
- 모바일 반응형 정상 작동


## 중간고사 기능 구현

### 추가한 기능
7주차에 만든 PC Help Guide에 문제 해결 결과 저장 기능을 추가했다.

사용자가 문제 해결 여부를 선택하고 저장하면 문제 해결 기록 탭에서 확인할 수 있다.
localStorage를 이용하여 새로고침 후에도 기록이 유지되도록 했다.

### 사용자 흐름
1. 기존 문제 해결 4단계를 완료한다.
2. 해결됨 또는 미해결을 선택한다.
3. 해결 결과 저장 버튼을 클릭한다.
4. 문제 해결 기록 탭에서 저장한 내용을 확인한다.

### 구현한 기능
- click 이벤트: 해결 결과 저장 및 기록 조회
- change 이벤트: 해결 상태 선택 및 오류 해제
- 결과를 선택하지 않으면 오류 메시지 표시
- 해결됨 선택 시 저장 완료 메시지 표시
- 미해결 선택 시 미해결 기록 안내
- 저장된 기록이 없으면 기록 없음 안내
- 다시 시작 시 현재 입력 상태 초기화
- localStorage를 이용하여 저장 기록 유지
- 저장된 문제 해결 기록을 개별적으로 삭제할 수 있도록 구현

### 테스트 결과
- 해결 결과 저장: 정상 작동
- 결과 미선택 시 오류 안내: 정상 작동
- 해결됨 및 미해결 메시지 표시: 정상 작동
- 저장 기록 조회: 정상 작동
- 새로고침 후 기록 유지: 정상 작동
- 다시 시작 기능: 정상 작동
- 모바일 390px 화면: 정상 작동
- 기록 삭제 및 취소 기능 정상 작동


## 9주차 조건부 입력 폼 구현

### 추가한 기능
- 문제 해결 결과가 '미해결'일 때 추가 증상 입력창 표시
- 선택에 따라 입력창 활성화 및 비활성화
- 추가 증상 5자 이상 입력 검사
- 입력 중 글자 수 표시 및 오류 해제
- submit 이벤트를 이용한 결과 저장 및 중복 제출 방지
- 저장 성공 및 실패 메시지 표시

### 사용자 흐름
1. 문제 해결 과정을 완료한다.
2. 해결됨 또는 미해결을 선택한다.
3. 미해결인 경우 추가 증상을 입력한다.
4. 해결 결과를 저장하고 기록을 확인한다.

### 테스트 결과
- 미해결 선택 시 추가 입력창 표시: 정상 작동
- 5자 미만 입력 시 오류 표시: 정상 작동
- 5자 이상 수정 후 오류 해제: 정상 작동
- 해결됨 선택 시 추가 입력창 비활성화: 정상 작동
- 저장 성공 및 중복 제출 방지: 정상 작동
- 다시 시작 시 입력 상태 초기화: 정상 작동
- 모바일 화면에서 입력 및 버튼 조작: 정상 작동
